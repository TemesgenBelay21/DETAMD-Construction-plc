# DETAMD Construction PLC — Website

Official frontend website for **DETAMD Construction PLC**, built with **React.js** 
using modern styling and development practices.

## About the Project

This repository contains the source code for DETAMD Construction PLC's official 
website — a modern, responsive frontend designed to showcase the company's 
identity, services, and portfolio of work to potential clients and partners.

The site is built with a component-based architecture using React.js, focusing on 
clean design, performance, and a smooth user experience across devices.

## Sections

The website consists of six main sections:

- **Hero** — Landing section introducing the company and its core message
- **About Us** — Company background, mission, and values
- **Why Choose Us** — Key strengths and what sets DETAMD apart
- **Services** — Overview of construction services offered
- **Projects** — Portfolio of completed and ongoing projects, with filters to 
  browse by project type
- **Contact** — Contact details and inquiry form for potential clients

## Tech Stack

- React.js
- Modern CSS / styling approach
- Vite (build tool)

## Getting Started

Clone the repository:
```bash
git clone <repo-url>
cd DETAMD-Construction-plc
```

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

## Collaboration Workflow

This project is developed collaboratively using **Git branching** to isolate work 
per section/feature, with changes reviewed and merged into `main` via Pull Requests.
